# ARIA — Fashion Website

Welcome to **ARIA**, a fashion website created as a front-end web development project.

ARIA is designed as a simple, modern, and elegant online fashion store where users can explore different categories of clothing and accessories. The main focus of the project was to create a visually appealing website while keeping the interface easy to navigate and responsive across different screen sizes.

## 🌸 About the Project

The idea behind ARIA was to create a fashion website that feels clean, stylish, and easy to use. The website includes different fashion categories along with pages for shopping, login, and contacting the brand.

This project helped us understand how a real website is structured and how different HTML and CSS concepts can be combined to create a complete front-end website.

## 🛠️ Technologies Used

* **HTML5** — Used to create the structure and content of the website
* **CSS3** — Used for styling, layouts, animations, and responsiveness
* **CSS Media Queries** — Used to make the website responsive on different screen sizes

## 🎨 Design

The design of ARIA follows a minimal and elegant fashion aesthetic. We focused on maintaining a consistent look throughout the website using suitable typography, spacing, images, colors, and layouts.

The aim was to make the website look like a real fashion store while also keeping the design simple enough for users to navigate comfortably.

## 📱 Responsive Design

The website is designed to work on different screen sizes, including desktops, tablets, and mobile devices.

CSS media queries are used to adjust layouts, spacing, grids, and other elements according to the screen width.
